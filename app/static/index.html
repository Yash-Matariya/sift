Sift

ask your documents — answers cite their sources

1  Add a document

PDF, text or markdown. Chunking and embedding run in a background worker, so the upload returns straight away and the status flips to ready when it is searchable.

2  Ask a question

The agent retrieves, grades whether what it found is actually good enough, rewrites the query and tries again if it is not — then answers from those passages, or declines.

Answer

Sources

Built from the passages actually sent to the model — so they cannot be invented.
